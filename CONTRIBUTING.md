## Разработка

### Требования

- Node.js 18+
- npm 9+
- Chrome 105+

### Установка

```bash
git clone https://github.com/VKify/vkify-extension.git
cd vkify-extension
npm install
```

### Сборка

```bash
npm run build        # prod-сборка → dist/
npm run build:fast   # prod без typecheck
npm run build:dev    # dev-сборка (localhost-мост, console.* сохранены)
npm run dev          # dev-сервер попапа с hot reload
```

### Загрузка расширения в Chrome

1. Выполни `npm run build` (или `build:dev` для разработки).
2. Открой `chrome://extensions`.
3. Включи **«Режим разработчика»**.
4. Нажми **«Загрузить распакованное»** и выбери папку `dist/`.
5. После каждой пересборки нажимай кнопку обновления расширения на той же странице и перезагружай открытые вкладки vk.com.

### Тесты и проверки

```bash
npm run typecheck    # проверка TypeScript
npm test             # запуск тестов (Vitest)
npm run test:watch   # тесты в watch-режиме
```

Перед открытием PR убедись, что `typecheck` и `test` проходят без ошибок.

## Правила оформления PR

1. **Одна задача — один PR.** Не смешивай несвязанные изменения.
2. **Ветка от `main`.** Название ветки: `fix/краткое-описание` или `feat/краткое-описание`.
3. **Typecheck и тесты проходят.** CI проверяет это автоматически.
4. **Описание PR** — что изменено и зачем. Ссылка на issue, если есть.
5. **Нет новых `console.log`** в продакшн-коде (они вырезаются при сборке, но лишний шум мешает review).
6. **Безопасность.** Если затрагиваешь `settings-schema.ts`, `message-handler.ts` или любой код, пересекающий границу доверия (site-bridge, postMessage, импорт настроек) — особенно тщательно проверь валидацию и добавь тест.

## Структура проекта

Краткая карта для быстрой навигации:

| Путь | Описание |
|------|----------|
| `src/background/` | Сервис-воркер: VK API, алармы, уведомления |
| `src/content/` | Контент-скрипты: фичи на странице VK |
| `src/content/injected/` | Скрипты в page context (spy, блокировка рекламы) |
| `src/popup/` | React-приложение настроек (10 вкладок) |
| `src/shared/` | Общий код для всех слоёв (константы, утилиты, схема настроек) |
| `src/types/index.ts` | Все TypeScript-типы проекта |
| `scripts/build.mjs` | Оркестратор сборки (ESM + IIFE) |

Подробнее — в разделе [«Структура проекта»](README.md#структура-проекта) основного README.
