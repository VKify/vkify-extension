# Политика конфиденциальности VKify

Дата вступления в силу: 23.01.2026

## 1. Сбор данных

Расширение VKify **НЕ собирает, НЕ хранит и НЕ передаёт** никакие персональные данные пользователей третьим лицам.

## 2. Локальное хранение

Расширение сохраняет пользовательские настройки (тема, скрытые элементы, параметры блокировки рекламы) **только локально** в браузере с использованием Chrome Storage API. Эти данные:
- Не покидают ваш браузер
- Не отправляются на внешние серверы
- Не передаются третьим лицам

## 3. Разрешения

Расширение запрашивает следующие разрешения:
- **storage** — сохранение настроек локально
- **tabs** — применение настроек к вкладкам vk.com
- **host_permissions (vk.com)** — работа только на сайте ВКонтакте

## 4. Доступ к сайтам

Расширение работает **исключительно** на сайте vk.com и не имеет доступа к другим веб-сайтам.

## 5. Изменения политики

При существенных изменениях политики конфиденциальности пользователи будут уведомлены через обновление расширения.
